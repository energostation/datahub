# MQTT

## Topic format

```
plc/v1/{PROJECT_ID}/{PLC_ID}/message
```

## Payload format

```json
{"timestamp": "2025-10-17 10:22:19.030705", "argument": "FB_TEST.TEST_ARG", "value": 3.14}
```

## Setting up a PLC client

PLC configuration (certificates, credentials) is generated by the configurator and deployed there via the "Deploy embedded API" button.

To allow a PLC to connect to the broker, the encrypted configuration bundle from the configurator must also be sent to DataHub:

```shell
curl \
  -X POST \
  -H "Authorization: Token $ENERGO__DATA_API__MANAGE_API_TOKEN" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "password=$PASSWORD_BUNDLE" \
  -d "content=$ENCRYPTED_CONFIG_BUNDLE" \
  "https://api.docker.localhost/manage/config/"
```

Alternatively, use the config UI at `https://config.docker.localhost`.

## Publishing data manually

Without TLS (direct broker access, port 1883):

```shell
mosquitto_pub \
  -h <IP_ADDRESS_OF_MQTT_BROKER> \
  -p 1883 \
  -i $CLIENT_ID \
  -u $MQTT_USERNAME \
  -P $MQTT_PASSWORD \
  -t plc/v1/${PROJECT_ID}/${PLC_ID}/message \
  -m '{"timestamp": "2025-10-17 10:22:19.030705", "argument": "FB_TEST.TEST_ARG", "value": 3.14}'
```

With TLS through Traefik (port 8883), using client certificate:

```shell
mosquitto_pub \
  -h mqtt.docker.localhost \
  -p 8883 \
  --cafile $MQTT_CA \
  --cert $MQTT_CERT \
  --key $MQTT_KEY \
  -i $CLIENT_ID \
  -u $MQTT_USERNAME \
  -P $MQTT_PASSWORD \
  -t plc/v1/${PROJECT_ID}/${PLC_ID}/message \
  -m '{"timestamp": "2025-10-17 10:22:19.030705", "argument": "FB_TEST.TEST_ARG", "value": 3.14}'
```

## Authentication and authorization

VerneMQ uses the `mqtt` PostgreSQL database for authentication and ACL checks (via the `vmq_diversity` plugin with the `auth_postgres` backend). Credentials are managed through the Data API.
